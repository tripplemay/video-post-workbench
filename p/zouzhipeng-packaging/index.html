SEC 01 · Upstream

上游：纯净版怎么来的

包装之前还有一条重剪管线——从 4.7 小时原始素材，到 31:29 的纯净版。

原料是 191GB 广播级素材（三机位访谈 5 个 take + 约 110 段 B-roll）。重剪管线约 14 小时 （7-21 晚 → 7-22 午）跑完代理、转写、语义标注与十五版粗剪，交出包装管线的输入—— 1920×1080 · 31:29 的「纯净版」。以下每一步的产物都留在工作目录里，可复查。

01 · PROXY
四机位代理
原始素材转 720p 代理（detail / fu / wide / zou 四路），工作集独立，原素材只读不动。
02 · TRANSCRIBE
四轮转写
5 个 take 同期声逐轮重转（transcript → transcript4），sync_offsets.json 记录机位同步偏移。
03 · SEMANTICS
语义标注
逐 take 语义标签多轮迭代（final → v2 → v4），访谈变成可检索、可纸面剪辑的素材。
04 · ROUGHCUT
十五版粗剪
roughcut_v1–v15（720p）：结构、节奏、取舍逐版逼近，每版整条渲出看整体。
05 · MIX & QA
混版与核验
音频混版 v5 / v8 / v10 / v13；逐版转写回听核对（v*check），最终产出 31:29 纯净版。

SEC 03 · Visual System

视觉系统：卡片即叙事

包装不只是美化——数据卡回答疑问，章节卡提出悬念，金句卡钉住情绪锚点。

全套卡片由 gen_cards.py 用 Pillow 直接绘制：暖金黄 #D4AF37 取自栏目「福」字 logo， 纸色文字、细线双框、衬线标题。版式即品牌，页面亦沿用同一套语言。

章节卡 · PART 01「自讨苦吃 甘之如饴」—— 60% 压黑底上叠加，画面保持可见

章节卡 · 套一版式

五张卡：序章 + PART 01–04。版式四层信息——金色 PART 序号（字距拉宽）、 衬线大标题、金色短线、一行灰色「题眼」。

题眼让观众带着问题进入下一幕：PART 04 的题眼是「他也怀疑过自己 但从未停下」。

卡片以 60% 压黑底叠加在画面上、alpha 淡入淡出 0.4s， 每章停留 3.2s——是段落缓冲，也是叙事标点。

数据卡与人名条 · 落版规则

数据卡落在左下象限：深色半透明面板 + 金色竖线锚定，一屏一数， 静态大数字——不做滚动动画，克制才可信。

人名条同一锚点语言：姓名大字 + 身份小字 + 左侧金色竖线， 出现 6s，alpha 淡入淡出。

所有卡片与字幕共用原片时间坐标系，落点写死在 render.py 的 OVERLAYS 表里，随时可改可重渲。

SEC 04 · Subtitles

字幕：925 条的规则与兜底

模型转写只是底稿——真正的工艺在纠错词典、断行算法与克制强调。

管线做了什么

  • ASR 逐句底稿 → 42 条分段覆盖 + 60 余条全局纠错词典 → 样式 A 的 ASS 文件，共 925 条事件。
  • 样式 A：微软雅黑 Bold 白字 + 半透明黑描边 + 柔影，\fad(200,150) 淡入淡出——调研验证白字黑边可见性最优。
  • 排版铁律：每行 ≤16 字、最多两行；双行按「下重金字塔」断行——下行不短于上行，split_two 在空格处评分选点。
  • 标点：逗号句号一律以空格代替，保留顿号、书名号、问号。

规则与兜底

  • 纠错对照（词典示例）：
    周老师→邹老师 · 苹果楼→拼多多 · 实质力量→师资力量
    英体美→音体美 · 风雪寺→风穴寺 · 感染值→橄榄枝
  • 误伤防护：「自教→支教」会误伤「亲自教」——先以 \x00 占位保护，替换完再还原。
  • 关键词暖金强调：#D4AF37 只给「100块 / 2000名 / 倒贴 / 傻子」这类金句词，克制使用，不用花字。
  • 抑制窗口：B-roll 遮盖段（48.44–53.04s）不压字幕；尾声固定文案段整段不加字幕。
SEC 05 · Voiceover

旁白：一次合成，七段落点

音色统一靠「一次说完」，切分靠模型自己听回来。

访谈主体段落一律不加旁白，保住对谈现场感。旁白只落在序章 6 句与尾声引入 1 句， 承担设问、转折与时空跨越。全部 7 段已改用福哥克隆音色——由栏目创办人亲自「讲述」，叙事更贴身。

旁白文案→ 福哥克隆音色 TTS 整段一次合成→ whisper large-v3 词级时间戳切句→ 音频链→ 落点混入 · 侧链闪避

生成与切分

  • 从成片同期声取福哥声音样本，在 TTS 平台克隆音色（speaker 挂载）；7 句文案一次合成，音色从头统一到尾。
  • 合成音频再喂给 faster-whisper large-v3，按词级时间戳找回每句起止，切成 vo_p1–p6。
  • 逐段音频链：highpass 80Hz → deesser 去齿音 → 压缩 3:1 → 12kHz 搁架 −1.5dB → 微量 aecho 空间 → loudnorm −19 LUFS。
  • 尾声旁白落点 = 片头 3.04 + 序章 45.40 + 正片 1763.78 + 0.5 ≈ 1812.7s，以 sidechaincompress 侧链闪避把访谈声压下去再进入。

混音关系

  • 旁白电平整体低于访谈对白主体，闪避参数 threshold 0.01 / ratio 10 / release 700ms——让得开、回得来。
  • 序章旁白垫在音乐床之上：音乐床复用正片片尾两段，volume 0.30 / 0.48 分层淡入。
  • 最终全片再过两遍法 loudnorm（I=-16 / TP=-1，linear），网络长视频响度标准。
Symptom · 症状
旁白一说完，全片失声
第一版混音输出里，尾声旁白播完后，剩余部分的音轨整体消失。
Cause · 根因
侧链流 EOF 拉停全图
sidechaincompress 的旁白输入流较短，到达 EOF 时把整个 filter 图提前终止，主音频随之中断。
Fix · 修复
apad 补静音 + 时长校验
旁白流先 apad 补静音再进侧链；输出后强制校验——音轨与视频时长差 <0.5s 才放行。

SEC 07 · Render

渲染：一条 filter_complex 装配主片

29:27 主片，一条命令——每个落点都是数据，每次重渲都可复现。
纯净版 m4v→ colortemperature 6000 轻暖→ 遮盖窗 ×2→ 支教经历卡 ×6 层→ ass 字幕烧录→ overlay ×10 卡片落版→ yuv420p · bt709→ h264_nvenc cq20

四处修复

  • 片头迁移：原片 0–29.92s（蒙太奇 + 栏目片头）整段跳过；其中 26.88–29.92s 芥末黄栏目卡剪出，移到序章之前作 3 秒片头。
  • 静止照片遮盖：48.44–53.04s 为定格照片无内容，用课堂动态 B-roll 遮盖（eq 近似校色，窗口内同步抑制字幕）。
  • 烧录字幕段替换：1428–1453.4s 残留原片烧录字幕，用 Take3 同机位素片逐镜头替换（6 个镜头，素材偏移 1135.91s 对齐）。
  • 旧尾声替换：1793.70s 起的旧尾声由新片尾替代——build_ending.py 单独装配，与正片同质感同响度。

落版与音频

  • 10 组 overlay + 支教经历卡 6 层全部带 alpha 淡入淡出（0.4–0.5s）；经历卡常驻面板置于字幕层之下，五条经历逐条显现；数据卡、人名条、金句卡以 crop 取版落位。
  • 字幕与卡片共用原片时间坐标系；试渲染 --ss 任意片段时，ASS 与落点自动平移。
  • 音频：afade 入场 + loudnorm 两遍法（I=-16 / TP=-1 / LRA=11，linear）→ AAC 320k / 48kHz。
  • 诚实注明：方案中的 vignette、胶片颗粒、章节进度角标，当前未进滤镜链——见「还缺什么」。
